# 폰에서 봇 화면 열기 (Tailscale)

봇 서버는 보안상 **이 PC 안(127.0.0.1)에서만** 열려 있어요. 폰에서 보려면 무료 사설망 **Tailscale**을 씁니다.
내 기기끼리만 암호화로 연결되고 인터넷에는 공개되지 않아요. 와이파이·LTE 어디서나 열려요.

## 처음 한 번
1. **PC**: https://tailscale.com/download/windows 에서 설치하고 로그인
2. **폰**: 앱스토어/플레이스토어에서 `Tailscale` 설치하고 **PC와 같은 계정**으로 로그인한 뒤 연결 켜기
3. 봇 켜기: `start.bat`(테스트) 또는 `start-24h.bat`(24시간)
4. `phone-on.bat` 더블클릭 → 화면에 나온 `https://<PC이름>.<tailnet>.ts.net` 주소를 폰 브라우저에서 열기
   - 처음에는 "HTTPS 사용 허용" 링크가 나올 수 있어요. 열어서 허용한 뒤 다시 실행하세요.
   - 폰 홈 화면에 바로가기로 추가해 두면 앱처럼 쓸 수 있어요.

## 끄기
`phone-off.bat` — 폰 접속만 끄고, 봇은 PC에서 계속 돌아가요.

## 알아둘 점
- PC가 켜져 있고(절전 X) 봇이 실행 중이어야 열려요.
- `start.bat` ↔ `start-24h.bat`을 바꿔 켰다면 `phone-on.bat`을 다시 실행하세요(포트가 달라요: 5173 / 8787).
- **같은 Tailscale 네트워크(tailnet)에 있는 모든 기기**가 이 화면을 열 수 있어요. 회사·지인과 함께 쓰는 tailnet이면 개인 계정으로 따로 만드세요.
- 화면 주소는 포트포워딩·공유기 설정 없이 동작해요. 공유기 포트를 열어 인터넷에 직접 공개하지 마세요(봇 화면에 매매 버튼이 있어요).
- 오라클 클라우드에서 돌리는 경우에도 서버에 Tailscale을 설치하고 `sudo tailscale serve --bg 8787` 하면 같은 방식으로 폰에서 열 수 있어요.
