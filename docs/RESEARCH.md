# 전략 연구 기록 (BTC · ETH · XRP)

> ⚠ 과거 데이터로 한 실험이에요. 앞으로의 수익을 보장하지 않아요. 투자 판단은 본인 책임이에요.

다시 돌리기: `npm run research` (전체 비교) · `npm run research -- --units 60m --robust 볼린저회귀` (견고성 점검)

## 실험 방법 (공정하게 하려고 지킨 것)
- 캔들이 **닫힌 뒤** 신호 판단 → 다음 캔들에서 진입(미래 데이터 사용 금지)
- 수수료 0.05% × 2 + 시장가 미끄러짐 0.05% × 2 포함
- 손절·익절이 한 캔들 안에서 둘 다 닿으면 **손절이 먼저**라고 가정. 지정가로 체결된 그 캔들에서는 익절로 치지 않음
- 파라미터는 **앞 70%(학습)** 에서만 고르고, **뒤 30%(검증)** 는 고른 뒤 한 번만 확인
- 세 코인에 **같은 파라미터**(코인별로 따로 맞추지 않음)
- 기간: 60분봉 4년(2022-10~2026-10), 4시간봉·일봉 6년

### 볼린저 반등 (60분봉, EMA100 위, 볼린저 20·2.5σ, 중심선 복귀 매도, 최대 50봉)
- 4년 · 세 코인 합산: **승률 70.9%, PF 1.87, 175번, 1회 평균 +0.34%**
- 연도별(승률/PF): 2023 62%/1.57 · 2024 72%/1.54 · 2025 81%/3.25 · 2026 68%/1.85 — 매년 PF > 1
- 최악 1회 −8.1%, 코인별 최대 낙폭 최대 13.6%
- 코인별 PF: BTC 1.90 · ETH 3.37 · **XRP 1.06(거의 본전)**
- 이웃 설정도 비슷(k=2~3, 보유 30~50봉) → 한 점만 우연히 좋은 게 아님. 단, 4시간봉에서는 약해짐(승률 65%)
- 고정 손절(ATR 3~8배)을 넣으면 오히려 나빠짐 → 시간 손절 + 넓은 안전장치 손절(8%)만 사용
- 단점: **자주 안 사요**(코인당 한 달 1~2번), 1회 수익이 작아요. 하락장에서는 대부분 쉬어요

## 손익비 3:1 · 승률 70%에 대해
- 3:1이면 본전 승률은 약 27~30%. 실험에서 3:1 전략들은 승률 25~35%였어요.
- 승률 70%는 "작은 익절 + 넓은(또는 시간) 손절" 구조에서만 나왔고, 대부분 검증 구간에서 손실이었어요.
- 승률만 보지 말고 **PF(총이익÷총손실)와 최대 낙폭**을 같이 봐야 해요.
